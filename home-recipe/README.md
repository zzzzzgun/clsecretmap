# わが家のレシピ（えまたくおしんひろのレシピ）

家で作った料理のレシピを記録しておく Web アプリです。
ログインもサーバーも不要で、データは**この端末のブラウザの中（localStorage）だけ**に保存されます。

公開URL: https://zzzzzgun.github.io/clsecretmap/recipe-note/

## できること

| 画面 | 内容 |
| --- | --- |
| 一覧（起動時の画面） | 上にアイコンと「えまたくおしんひろ のレシピ」のロゴ。登録したレシピの一覧。検索窓はスクロールしても上に固定。料理名・材料・調味料の**部分一致**で検索（スペース区切りで AND、ひらがな／カタカナ・全角／半角は区別しない）。検索対象を「すべて／料理名／材料・調味料」で切り替え、並び順は「更新が新しい順／名前順／評価が高い順」 |
| 登録・編集 | 料理名（必須）・説明・何人分のレシピか（最初は4人分）・作り方（手順の追加・並べ替え）。材料と調味料は候補から**タップで選ぶ**（候補にないものは名前を入れて追加、過去のレシピで使ったものも候補に出る）。量は「1」「1.5」「1/2」「1と1/2」で入力、**単位は選択式**（大さじ・小さじ・カップ・g・ml・個・本・少々・適量 など） |
| 詳細 | **食べる人数を ＋／− で変えると量を計算し直す**（大さじ1と1/2、約133g のように料理らしく表示。小さじ3杯以上は「＝大さじ1」、大さじ1未満は「＝小さじ…」も表示。少々・適量はそのまま） |
| 評価 | 「😋 みんな食べた／🙌 えまたく2人とも食べた／🙋 えまだけ食べた／🙋 たくだけ食べた」から選んで、日付とひとことメモ付きで登録。履歴と回数が見られ、一覧にも最新の評価が出る |
| 削除 | 詳細画面の「このレシピを削除」→ **確認のダイアログ**で「削除する」を押したときだけ削除 |

## 使い始める

```bash
cd home-recipe
npm install
npm run dev
# 表示された http://localhost:5173 を開く。同じ Wi-Fi のスマホからは Network の URL で開ける
```

一覧が空のときは「サンプルを入れて試してみる」で、肉じゃが・鶏の照り焼きの2件が入ります。

> ⚠️ データは端末のブラウザの中だけにあります。ブラウザのデータを消す・機種変更すると消えます（プロトタイプのため、バックアップ機能はまだありません）。
> iPhone では、ホーム画面に追加してから使うと消えにくくなります。

## 開発

```bash
npm test          # 量の読み取り・人数での計算・表示・検索・保存のテスト
npm run typecheck
npm run build

# ブラウザでの通し確認（登録 → 人数の変更 → 評価 → 編集 → 検索 → 削除の確認 → サンプル）
npm run build && npm run preview   # 別のターミナルで
npm run e2e                        # スクリーンショットは e2e/output/ に出る

# GitHub Pages 用の公開ファイル（../recipe-note）を作り直す
npm run publish
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src/model.ts` | データの型、単位、材料・調味料の候補、評価の選択肢 |
| `src/amount.ts` | 量の読み取り（1と1/2 など）、人数での計算、表示 |
| `src/search.ts` | 部分一致検索・並び替え・ハイライト |
| `src/storage.ts` | localStorage への保存（壊れたデータは退避してから空で始める） |
| `src/store.tsx` | 状態管理とトースト |
| `src/views/` | 一覧・詳細・登録/編集の画面 |
