# デイ手帳（家庭用）

放課後等デイサービスの利用日、デイでの様子、お子さんのサポートブックを、**この端末の中だけ**にまとめる家庭用ツールです。
ログインもサーバーも不要で、入力した内容はインターネット上のどこにも送られません。

製品版（`../houday-poc`）の前に、自分の家庭で毎日使って「本当に必要な機能」を確かめるためのものです。
利用日数・重複・期限の計算は製品版と同じコード（`houday-poc/src/lib/domain`）を使っています。

## できること

| 画面 | 内容 |
| --- | --- |
| カレンダー | 全てのデイの予定を1か月表示に。支給日数の残り、同じ日に2か所入っている日（1日1事業所ルール）の警告、受給者証の期限（60日前から）の通知。曜日でまとめて入力できる |
| 様子 | デイの連絡帳や迎えのときに聞いたことを、写真付きで時系列に記録。デイごとに絞り込める |
| サポートブック | 7項目。書き直すと前の内容が履歴に残る（1項目50件まで）。印刷 / PDF保存 |
| 連絡 | 学校向けの週の予定（どのデイが何時に迎えに来るか）をコピー・印刷。デイ向けの「来月の利用希望日」の文面を、デイごとに自動作成してコピー |
| 設定 | デイ・受給者証・お子さん（きょうだいも可）・バックアップ |

## 使い始める

### パソコンで試す

```bash
cd houday-family
npm install
npm run dev
# 表示された http://localhost:5173 を開く。同じ Wi-Fi のスマホからは、表示された Network の URL で開ける
```

### スマホで毎日使う

ファイルを置いておく場所（静的ホスティング）が必要です。データは端末の中にあるので、置くのは画面のプログラムだけです。

1. `npm run build` を実行すると `dist/` フォルダができる
2. どれか1つの方法で公開する
   - **[Netlify Drop](https://app.netlify.com/drop)**：`dist/` フォルダをブラウザにドラッグするだけ（一番かんたん）
   - **Cloudflare Pages**：リポジトリをつなぐ場合は、ルートディレクトリを `houday-family`、ビルドコマンドを `npm run build`、出力先を `dist` にする（ビルド時に `../houday-poc` も使うので、リポジトリ全体をつなぐ）
3. スマホでその URL を開き、**ホーム画面に追加する**
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「ホーム画面に追加」

> ⚠️ **iPhone では必ずホーム画面に追加してから使ってください。** Safari のタブで開いたまま使っていると、しばらく開かなかったときにデータが消されることがあります。ホーム画面に追加したものは対象外です。

## バックアップ（大事）

データは端末の中だけにあるので、機種変更・端末の紛失・ブラウザのデータ削除で消えます。

- 設定 →「バックアップを書き出す」で、写真も含めた1つのファイルができる
- そのファイルを iCloud Drive や Google ドライブなど、**端末以外の場所**にも保存する
- 戻すときは、設定 →「バックアップから戻す」でそのファイルを選ぶ（今のデータは置き換わる）
- 前回から30日たつと、設定画面でお知らせする

もう一人の保護者のスマホに移したいときも、バックアップファイルを渡して読み込めば同じ内容になります（同時に編集して自動で同期する機能はありません。必要になったら製品版の出番です）。

## 開発

```bash
npm test          # データ処理・文面・バックアップ・保存のテスト
npm run typecheck
npm run build

# ブラウザでの通し確認（初回登録 → デイ・受給者証 → 予定 → 重複警告 → サポートブック
# → 様子の記録と写真 → 連絡の文面 → 再読み込み → バックアップと復元）
npm run build && npm run preview   # 別のターミナルで
npx playwright install chromium    # 初回だけ
npm run e2e
```

## 製品版との違い

| | 家庭用（これ） | 製品版（houday-poc） |
| --- | --- | --- |
| データの置き場所 | この端末の中だけ | 日本国内のサーバー（Supabase） |
| ログイン | 不要 | メールのリンク |
| 学校・デイとの共有 | 文面のコピー・印刷 | 期限付きの共有リンク |
| 様子の記録・写真 | あり | まだない（第2段の候補） |
| 来月の希望日の文面 | あり | まだない |
| 家族で同時に使う | できない（バックアップで移すだけ） | 第2段で家族招待 |

家庭用で「毎日・毎月使ったもの」「使わなかったもの」をメモしておくと、製品版で何から作るかの一番の判断材料になります。
